# Vision

Long-term direction for Webway's cognitive-architecture research program.
Inherited from MONOLITH's Phase 1 — see `../MIGRATION_NOTE.md` for provenance.

Vision documents describe where the research is going, not what exists
today. They are not commitments. They are not timelines. They are direction.

For what is implemented today, see `../webway-v0.md`.
For the decisions that shaped this vision, see `../adr/`.
For the research that informed those decisions, see `../research/`.

## Vision Principles

- Vision documents do not define implementation.
- Vision documents do not supersede architecture documents.
- When a vision concept is ready to implement, it first becomes a research document (R-XXXX), then an ADR, then an architecture document.
- Vision documents are updated when direction changes, not when implementation progresses.
